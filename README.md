# Portfolio — Pierre Untersinger (Epitech 2026 / Promo 2028)

Portfolio personnel interactif développé en **React 19**, avec animations 3D **Vanta.js / Three.js**, gestion du thème sombre/clair, formulaire de contact et présentation de projets personnels & académiques Epitech.

---

## 🚀 Démarrage rapide

### 1. Aller dans le dossier du projet
```bash
cd portfolio-v1.2.0/portfo
```

### 2. Installer les dépendances
```bash
npm install
```

### 3. Lancer l'application en développement
```bash
npm start
```
L'application sera accessible sur : **http://localhost:3006**

---

## 📦 Scripts disponibles

Depuis le dossier `portfolio-v1.2.0/portfo` :

- `npm start` : Démarre le serveur de développement React (port 3006).
- `npm run build` : Génère le bundle de production optimisé dans `build/`.

---

## 🛠️ Stack technique

- **Framework** : React 19 (`react`, `react-dom`)
- **Routage** : React Router v7 (`react-router-dom`)
- **Animations 3D / Background** : Vanta.js (Net effect) + Three.js
- **Icônes** : React Icons (`react-icons/fa`, `react-icons/si`, `react-icons/md`)
- **Contact** : Web3Forms API (intégré via variable d'environnement `.env.local`)
